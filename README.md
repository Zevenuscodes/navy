# NavAyu Care

Website for Navayu Care, an Ayurvedic clinic in Harrawla, Dehradun.

A single static page (`index.html`) with no build step. The layout and styling follow https://navayu-care.grexa.site/:

- Contact strip, header and WhatsApp call-to-action
- Hero with an "at a glance" card and business-hours dialog
- Services grid, photo gallery and Google reviews carousel
- Dark footer with location card, plus a sticky contact bar
- Responsive down to phone width

## Run locally

```sh
python3 -m http.server 8080
```

Then open http://localhost:8080.
